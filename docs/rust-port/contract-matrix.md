### TurboQuant persisted-wire ownership decision

The bounded #1137 foundation compares only the eight-byte little-endian
`f32` min/max header, opaque packed bytes, and short-header error semantics.
`crates/symdesk-index/src/retrieval_quant_sidecar.rs::read_blob` deliberately
returns an owned snapshot. Pinned Go CoreKit v0.18.2
`vectorkit/turboquant.UnpackSidecarBlob` instead returns `Bytes: blob[8:]`, a
mutable alias of the caller's buffer. **This is an intentional Rust API
difference, not Go ownership parity.** Mutations do not propagate in either
direction in the Rust owned-value API; the named snapshot regression checks
that difference separately from the Go-derived wire comparator.

The persisted representation is unchanged. No existing Rust production
caller uses this new helper, and no codec, DB, CLI, scoring, or performance
claim depends on shared storage. A future caller that needs zero-copy views
must add a borrowed API with its own lifetime/mutation contract and tests;
the owned snapshot must not silently become an alias.

The generator records actual Go `EncodeSidecar`/`UnpackSidecarBlob` output
and verifies runtime module version, checksum, and absence of replacement
before generation or checking.

### TurboQuant local codec (#1137)

`crates/symdesk-index/src/turboquant/` ports the full pinned CoreKit codec:
Go `math/rand` rotation signs (including the copied `rngCooked` table),
Walsh-Hadamard rotation, uniform min/max quantization, LSB-first bit packing
for 2/3/4/2.5/3.5-bit widths, `Score`/`ScoreCosine`, the 32-byte metadata
header, `EncodeSidecar`/`DecodeSidecar`/`ValidateSidecarMeta`, Go error
strings and Go `json.Marshal` bytes for `SidecarMeta`.
`scripts/rust-port/cmd/turboquant-gen` records 18 sign sequences (up to 2048
draws, crossing the 607-entry ring), Hadamard/rotation `f64` bits, 60 codec
cases (12 inputs x 5 bit widths, dims 1..768, negative and >32-bit seeds,
zero/constant/extreme vectors), 21 metadata JSON cases and 21 error cases in
`testdata/port/retrieval/turboquant-codec.json`. Run
`make retrieval-turboquant-differential`.

Exact comparisons: packed codes, min/max, metadata bytes, metadata round-trip
encodes (including Go's `uint32` seed truncation), sidecar blobs and JSON,
rotations, scores and cosine scores in the 60-case grid fixture.

Property corpus (`testdata/port/retrieval/turboquant-property.json`): 200
generated cases from the pinned CoreKit package, dimensions 1..128 plus one
768-dim case, all five bit widths, full-range int64 seeds and scales from 1e-3
to 1e6. Encoded bytes and min/max are exact in Rust. **Declared tolerances:**
Go fuses `min+(max-min)*mid` and the score accumulation into FMA on arm64 but
not amd64, so Go's own decode and score bits differ by architecture. The corpus
records each decoded component and score with a bound derived from the exact
min/max and rotation: decode within `2^-20 * max(|min|,|max|)` and score within
`2^-16 * sum|rotated query| * max(|min|,|max|)`. Rust's worst decode is about 5%
of its bound and its scores match exactly. The generator check verifies the
same bounds on darwin/arm64 and darwin/amd64 (Rosetta).

Go reads Rust-written sidecars: `turboquant-sidecar-writer` renders one
`encode_sidecar` blob and metadata JSON per property case into
`testdata/port/retrieval/turboquant-rust-sidecars.json`, and
`TestGoReadsRustSidecars` decodes those bytes with the pinned CoreKit package.
The decode and score of each Rust blob must match the Go decode and score of
Go's own blob bit for bit on the same architecture, and the Go-serialised
metadata JSON must equal Rust's. Corrupting one Rust metadata field fails the
test. `make retrieval-turboquant-differential` runs all of these.

Intentional differences: Go `Score`/`ScoreCosine` panic on short packed codes;
Rust returns `0.0`. No Rust production caller is wired yet; DB backfill and
quantized search facades stay with RUST-008/INDEX-005.

`make retrieval-turboquant-benchmark` compares Go and Rust encode and
quantized-scan latency/throughput (best of alternating trials) and fails on a
Rust p95 or throughput regression above 10%; the committed report is
[turboquant-benchmark.md](turboquant-benchmark.md).
