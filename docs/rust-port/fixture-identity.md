# Fixture source identity

The live fixture source is **P**, the full lowercase commit and release in
`testdata/port/provenance.json`. P must exist in the checked Git history and its
complete Go production-source digest must equal the actual generating source.
The fixture-recording commit **Q** separately binds the generator-source digest,
the output checksums and the independent Go replay. Squash merges do not require
P to be Q's direct parent.

All live source headers (`oracle.commit`, scalar commit `oracle`,
`oracle_commit` and `oracle_revision`) must equal P. Any recorded live release
must equal P's release. The Go gate examines immutable Git blobs across
`testdata/port` and Rust test-data JSON, including files outside the output
manifest. Rust consumers read the frozen central identity; the Index identity
contract checks all manifest-covered output checksums and embedded live headers
without executing Go or Git. The sixteen Dataset CLI case definitions are
Go-owned generator inputs; their generated corpus carries the current P and is
replayed by the Go service contract and native CLI differential.

Three paths deliberately retain a historical identity **H**:

| Path | Role |
| --- | --- |
| `testdata/port/cli/cases.json` | Declarative differential input suite, not recorded Go observations |
| `testdata/port/cli/retention-cases.json` | Declarative retention differential input suite, not recorded Go observations |
| `crates/symdesk-index/tests/data/dataset_sync_time/provenance.json` | Frozen Go standard-library time probe, with its original source/probe/observation hashes and toolchain |

Their H commits must be full lowercase SHAs that exist in the checked ancestry.
Historical input suites are generator inputs, outside the derived-output
artifact allowlist. Their independent Go contract checks still run.
Roles belong to these paths, not a whitelist of acceptable SHAs. Their bytes are
also generator-source inputs, so changing a historical corpus requires deliberate
P/Q regeneration. They are never relabeled as current Go observations. Historical
VALUE performance reports keep their original baseline identities and are not
live fixture acceptance evidence.

The `oracle` strings in `vault/base-view-write.json` and
`vault/notebook-write.json` describe production APIs rather than commits. Only
those two exact path/description pairs have this descriptive role. Their generated
payloads still participate in Q's checksums and independent Go replay.

Make and Go generator defaults read central provenance. Full private generation
passes one selected P/release to every writer; selecting a different
`--fixture-oracle-commit` is rejected before execution. Package-local overrides
require `PORT_GENERATE=1` and both `PORTGEN_FIXTURE_SOURCE_COMMIT` and
`PORTGEN_FIXTURE_SOURCE_RELEASE`. Check processes strip both variables and their
case aliases, along with existing generation controls. Writers verify complete
production bytes before recording identities; source-set, ignored-input and
immutable-snapshot guards remain in force.

After a production change merges as P, generate from a clean checkout with:

```sh
make port-fixtures-generate PORT_ORACLE_COMMIT=$(git rev-parse HEAD) > q.patch
```

Review and apply the artifact, commit derived outputs as Q, then run
`make port-fixtures-check`. Harness-only changes can reuse the existing P when
the full production bytes remain identical. The checked-in migration to this
model is regenerated by actual Go writers; recorded output payloads are not
hand-edited to satisfy the identity gate.
