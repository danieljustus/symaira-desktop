## Evidence and exact commands

All local commands below are run in an isolated worktree on macOS arm64 with
Rust 1.98.0, Cargo 1.98.0, Go 1.27.1 (Go contract commands explicitly pin
`GOTOOLCHAIN=go1.26.6`), and synthetic fixture roots only:

```sh
cargo fmt --all --check
cargo test -p symdesk-protocol --locked mime
make value-001-evidence-tests
CARGO_TARGET_DIR="$(mktemp -d)" make mcp-differential
CARGO_TARGET_DIR="$(mktemp -d)" make representative-differential
CARGO_TARGET_DIR="$(mktemp -d)" make rust-version-contract
make test
make lint
make rust-gates
```

The final command outcomes are recorded in the integration PR and must be
rechecked at its exact head. The isolated target tests deliberately set
`CARGO_TARGET_DIR`; the Make recipes must build and execute the same selected
`debug/symdesk` or `release/symdesk`, not silently fall back to `target/`.

Historical VALUE-001 evidence is checked with `make value-001-evidence-tests`.
It does not approve a changed candidate. The only approval procedure for the
measured candidate `5088972aa7efadfdc7118549354e26d001c1ffad` is the explicit
clean-worktree command in [operations-gate-checkpoint.md](operations-gate-checkpoint.md).
No benchmark result is extrapolated to later source revisions.

## Current gaps and blockers

- `RUST-006` is not complete: native representative CLI/HTTP/MCP parity must
  execute on the exact proposed head on macOS, Linux, and Windows; PR-triggered
  native jobs are intentionally skipped and are not evidence.
- No fresh exact-candidate VALUE-001 approval exists for code after the measured
  `5088972a` candidate. A later candidate must be measured in a clean isolated
  checkout and independently accepted with its trusted digest.
- Matrix rows for full CLI flags/process lifecycle, MCP error/schema surface,
  authenticated HTTP, vault writes/data round-trip, release packaging, and
  native Swift-consumer transports remain `TODO`. Consequently `RUST-007` and
  later dependent work stay blocked.
- Cross-compilation is not accepted as a native runtime substitute. Swift apps
  remain deliberately out of the language port and are consumer gates only.

## Boundaries, consumers, and rollback

- Crate responsibilities and allowed dependency direction are in
  [architecture.md](architecture.md): `symdesk-core`, `symdesk-vault`,
  `symdesk-index`, `symdesk-protocol`, `symdesk-cli`, and `symroom-cli` are the
  currently materialized public Rust entry points. Go owns the authoritative
  Markdown vault state; SQLite remains derived where documented.
- Direct consumers remain the macOS CLI/events transport, iOS authenticated
  server API and security-scoped Files/iCloud access, plus CLI/MCP/API clients.
  Native helper and permission dependencies (OCR/PDF/external tools, keyrings,
  filesystem behavior, authenticated self-hosting) are still Go-contract
  obligations; none is assumed portable from a compile check.
- Reproduce the Go oracle with the pinned commit above and the fixture commands
  in the matrix. Roll back by keeping Go release binaries and reopening only
  isolated test copies with Go; production vaults and stores are never used by
  migration tests. Cutover fallback requirements are defined in
  [architecture.md](architecture.md#4-delivery-and-rollback).
