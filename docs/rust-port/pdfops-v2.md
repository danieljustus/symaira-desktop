# Renderer PDF safety contract v2

This is the scheduler-authorized correction of review R1–R4 and issue #1247,
not a claim of historical Go parity or completed RUST-011. The original Go pin,
fixtures and diagnostic captures remain unchanged. `reference-v2.json` names a
separate committed Go production reference; its identity is checked with the
existing complete-production-source verifier (including embedded assets and
module contracts), never merely a selected-file hash.

## Deliberate observable changes

1. Destinations must be new. Existing files, directories and dangling symlinks
   are refused. Same-file identity distinguishes input aliases (including hard
   links). Split preflights every final part before running a writer. Private
   0700 staging is on the destination filesystem; completed, validated 0600
   files are published with atomic create-if-absent hard links. A raced-in
   destination is never replaced or removed. On a multi-part publication failure,
   earlier newly-created parts may remain; this is not a multi-file transaction.
2. qpdf writes split, merge and rotate outputs from the original inputs, and
   every staged result must pass a separate `qpdf --check` with exit 0 before
   publication. No `--warning-exit-0`, repair-warning waiver or direct Poppler
   output publication remains. Selector split also needs Poppler pdfinfo for page
   count. Legacy barcode split remains qpdf-only and counts via `--show-npages`;
   Poppler-only availability no longer advertises a usable barcode splitter.
   Historical Poppler 26.10.0 output `/Size` failures remain failed evidence.
3. Operations have a 60-second deadline; split rejects page counts over 10,000.
   Both selectors reject expansions over 1,000,000 pages and avoid signed-limit
   loop overflow. Inputs must be regular files. The legacy barcode range writer
   uses one shared deadline across counting, all ranges, validation and publication,
   and the same stage-all/publish path as selector split. It rejects more than
   10,000 pages/parts and non-increasing, duplicate or out-of-document boundaries
   before writing. `part-N.pdf` names and empty-document metadata are retained;
   the final range now ends at the verified count instead of unbounded `z`.
   The old per-range `Extract` and invalid Poppler-only fallback are removed.
   No-split copies retain
   their no-tool behavior, stream at most 512 MiB and publish exclusively.
4. Unix tool execution owns a fresh process group, including descendants holding
   capture handles after leader exit. Cancellation, overflow and normal leader
   exit terminate the group. The direct child is reaped. Captured stdout and
   stderr are independently capped at 16 MiB in memory, with no disk capture.
   The Typst version probe shares these protections. A process which deliberately
   escapes the owned process group is outside this isolation guarantee.
5. PDF diagnostic quoting uses Go 1.26.9's Unicode 15.0 printable classification,
   including format/private/unassigned characters and supplementary `\\U` escapes.
   The table is generated by the actual pinned compiler and checked read-only by
   the owning gate. It avoids a renderer-to-vault dependency and shared lock edits.

## Evidence and remaining boundaries

`make render-differential` retains strict values/types/fields, complete argv,
filesystem effects, direct-child cancellation, Unicode cases, profile discovery,
comparator rejection controls and a readiness-based safety corpus. The latter
checks descendant exit/cancellation, stdout/stderr overflow and output races
against both real adapters. Outer cleanup means test FAILURE, not product PASS.
The installed-tool harness separately checks synthetic valid PDF inputs, semantic
output/text and malformed/alias behavior. Synthetic inputs are never oracle output.

Native non-Unix process-tree ownership is not implemented in this correction;
those platforms fail closed before launching a tool. Windows Job Object support,
Linux native execution, escaped-process sandboxing, full hostile-PDF/fuzz bounds,
Rust CLI/MCP wiring, Typst rendering and the rest of RUST-011 remain unaccepted.
This checkpoint cannot be published, released or used to remove Go without its
independent spec/parity and quality/security review and coordinator acceptance.

`testdata/port/render/v2/` retain their reviewed bytes. The local composition at

fixture writers and uses the genuine `portgen` generator and controlled P/Q
